##  How to Use This Repo

This repository is your **personal workspace for the entire course**. Follow the steps below to get started and submit your work.

### Step 1 — Fork the Repository

Click the **Fork** button at the top-right of this page to create your own copy of the repo under your GitHub account.

```
https://github.com/ayanhussain81/data-analytics-with-python
         ↓  click Fork
https://github.com/<your-username>/data-analytics-with-python
```

### Step 2 — Clone Your Fork Locally

```bash
git clone https://github.com/<your-username>/data-analytics-with-python.git
cd data-analytics-with-python
```

### Step 3 — Create Your Batch Folder

Inside the repo, create a folder with your name and batch number. Keep **all your class code, notes, and project files** inside it throughout the course.

```
data-analytics-with-python/
└── students/
    └── <your-name>-<batch>/        ← your personal folder
        ├── python-scraping/
        ├── data-analysis/
        └── powerbi-ml/
```

### Step 4 — Commit & Push After Every Class

After each class, stage your work and push it to your fork:

```bash
git add .
git commit -m "module: add <topic> notes and exercises"
git push origin main
```

### Step 5 — Submit via Pull Request

Once you have completed the course (or a major module), open a **Pull Request** from your fork back to the main repo to submit your work for review.

1. Go to your fork on GitHub
2. Click **Contribute → Open pull request**
3. Set the title to: `[Batch X] <Your Name> — Course Submission`
4. In the description briefly mention: modules completed, projects built, and any highlights
5. Submit — your instructor will review and provide feedback

> **Important — Course Content Changes:**
> Any changes to course content, folder structure, file paths, or the roadmap must be **discussed with Ayan first**. Do not modify, rename, or restructure any existing content without prior approval. If you have a suggestion or improvement, reach out and discuss it before making any changes. Unauthorised changes to course material will not be accepted in Pull Requests.

> **Note:** Keep your fork up to date with the main repo as new content is added by running:
> ```bash
> git remote add upstream https://github.com/ayanhussain81/data-analytics-with-python.git
> git fetch upstream
> git merge upstream/main
> ```

## 🗓 Course Summary

Welcome to **Data Analytics with Python** — a hands-on program that takes you from Python fundamentals to scraping live data and turning it into analysis, dashboards, and simple predictive models.

| Module | Topic |
|--------|-------|
| Module 1 | Python Foundations & Web Scraping |
| Module 2 | Data Analysis (Pandas, NumPy, Matplotlib, SQL) |
| Module 3 | Power BI & Machine Learning |


> Detailed weekly schedule and class-by-class breakdown will be published as the roadmap is finalized.

---

## 🐍 Module 1 — Python Foundations & Web Scraping

![Python](https://img.shields.io/badge/-Python-3776AB?logo=python&logoColor=white)

**What you'll cover:**
- Python fundamentals: data types, dictionaries, loops, conditions
- Functions, file handling, exception handling (try/except)
- Web scraping: fetching and parsing HTML, handling requests, turning scraped data into structured datasets

📖 **Book reference:** [Chapter 14 — Python Foundations](https://data-engineering-book.vercel.app/docs/part-02-python-engineers-tool/core-language/chapter-14-python-foundations)

## 📈 Module 2 — Data Analysis (Pandas, NumPy, Matplotlib, SQL)

![Pandas](https://img.shields.io/badge/-Pandas-150458?logo=pandas&logoColor=white) ![NumPy](https://img.shields.io/badge/-NumPy-013243?logo=numpy&logoColor=white) ![SQL](https://img.shields.io/badge/-SQL%20Server-CC2927?logo=microsoftsqlserver&logoColor=white)

**What you'll cover:**
- Pandas: Series & DataFrames, indexing (loc/iloc), filtering, groupby, merging
- NumPy: arrays, vectorized operations, statistics
- Matplotlib: line, scatter, histogram, and other chart types for exploring data
- SQL (MS SQL Server): querying, joins, and aggregation for analysis

## 📊 Module 3 — Power BI & Machine Learning

![Power BI](https://img.shields.io/badge/-Power%20BI-F2C811?logo=powerbi&logoColor=black)

**What you'll cover:**
- Power BI: building dashboards and reports from analyzed data
- Machine Learning fundamentals: linear regression and other introductory models

## 🏁 Capstone Project

The course closes with a **hands-on capstone project**: an end-to-end case study that ties the three modules together — collecting or scraping data, analyzing and storing it, and presenting findings through a dashboard and/or a simple predictive model.

**Why it matters:** This is where individual modules **come together**. Instead of isolated exercises, you practice scoping the problem, cleaning and analyzing real data, and presenting something concrete you can talk about in interviews or portfolios.

## ❓ Why These Technologies?

Python, Pandas, NumPy, Matplotlib, SQL Server, Power BI, and Machine Learning form a practical, end-to-end toolkit for data analytics — from collecting and processing data to analyzing it and communicating insights.

Each module builds on the previous one, reinforcing both theory and hands-on practice.

## 📝 Final Notes

Throughout this course you will engage in **hands-on projects, assignments, and real-world case studies** that simulate practical data analytics work.
